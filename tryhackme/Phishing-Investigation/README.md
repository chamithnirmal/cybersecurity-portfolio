# 🔐 TryHackMe - Phishing Investigation

## Overview

Completed the **Phishing Investigation** room on TryHackMe.

This room provided hands-on practice in investigating phishing emails and identifying indicators that can help determine whether an email is malicious.

## Skills Practiced

* Phishing email analysis
* Email header investigation
* Identifying suspicious senders
* URL and link analysis
* Recognizing social engineering techniques
* Identifying Indicators of Compromise (IoCs)
* Basic incident investigation
* Cybersecurity investigation techniques

## Key Learning

I learned how attackers use phishing emails to create urgency, impersonate trusted sources, manipulate links, and potentially compromise users.

I also practiced examining different parts of an email to identify suspicious indicators.
