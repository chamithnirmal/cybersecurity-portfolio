# 🔍 Wireshark Network Traffic Analysis

## Objective

The objective of this project is to learn how to capture and analyze network traffic using Wireshark.

## Tool Used

* Wireshark
* Windows
* Web Browser

## Concepts Investigated

* IP addresses
* Network protocols
* TCP
* UDP
* DNS
* Network packets

## Method

1. Started Wireshark.
2. Selected the active network interface.
3. Captured network traffic.
4. Visited several websites during the capture.
5. Stopped the capture.
6. Used Wireshark display filters to investigate different protocols.

## Filters Used

```text
dns
tcp
udp
http
```

## Findings

I observed different types of network traffic during the capture and investigated how protocols such as DNS, TCP and UDP appear in packet captures.

## What I Learned

Through this project I learned how network packets can be captured and examined using Wireshark.

## Future Improvements

I plan to learn more about packet analysis, suspicious network traffic and security investigations.
